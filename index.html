01 / CAPABILITIES

从网页内容到分页文档

适合长文预览、文档排版与打印准备。保持你的 HTML 内容，不需要重写成专用文档格式。

▤

表格按行续页

普通 tbody > tr 可跨页移动，拆表时重复 thead，保留列宽。

◫

内容整体换页

图片、视频以及标记了 data-page-atomic 的内容块不会从中间切开。

▧

页边界可配置

页面尺寸、留白、页眉页脚和版心线都可调整；版心线左右距离同时约束正文宽度。

↥

打印与框架接入

自动注入打印分页规则，并提供 HTML、Vue 3 与 React 入口。

02 / GET STARTED

选用你熟悉的接入方式

安装包后调用分页器；也可以在普通 HTML 页面里直接通过 CDN 引入。分页目标须先挂载到文档中。

快速接入v0.2.0
import { createPaginator } from "dom-inplace-paginator"

const paginator = createPaginator({
  page: { width: 800, height: 1080 },
  footer: {
    height: 30,
    render: ({ pageNumber, totalPages }) =>
      `第 ${pageNumber} / ${totalPages} 页`,
  },
})

const result = await paginator.paginate(
  document.querySelector("#content"),
)
console.log(result.pageCount)
<script setup>
import { vPageBreak } from "dom-inplace-paginator/vue"

const options = {
  page: { height: 1080 },
  footer: { height: 30, render: ({ pageNumber }) => `${pageNumber}` },
}
</script>

<template>
  <main v-page-break="{ ready: true, options }">
    <h1>需要分页的内容</h1>
  </main>
</template>
import { PageBreak } from "dom-inplace-paginator/react"

export default function Document() {
  return (
    <PageBreak options={{ page: { height: 1080 } }}>
      <h1>需要分页的内容</h1>
    </PageBreak>
  )
}
<script src="https://cdn.jsdelivr.net/npm/dom-inplace-paginator@0.2.0/src/index.js"></script>

<main id="content">
  <h1>需要分页的内容</h1>
</main>

<script type="module">
  const result = await window.DomPaginator
    .createPaginator({ page: { height: 1080 } })
    .paginate(document.querySelector("#content"))
  console.log(result.pageCount)
</script>

03 / TABLE PAGINATION

长表格，
按行跨页。

使用普通的 thead 和 tbody。当正文空间不足时，分页器会移动表格行，在续页复制表头。

到实验台看真实表格分页 ↗
01
普通表格

tbody > tr 按行处理，续页保留表头与列宽。

02
合并单元格

存在跨行或跨列的表格，给整个 table 加 data-page-atomic。

03
超高内容

单行或整块超过一页可用高度时会报错，需要调整内容或页高。

04 / API REFERENCE

常用配置，一表查清

选项中的长度均为 CSS 像素。页面高度需要包含页眉、页脚和上下留白。

分页器配置选项
配置默认值用途
page.width / height800 / 1080页面宽高，决定正文可用区域。
page.gap16预览时的页间距。
page.padding30 / 48 / 30 / 48上、右、下、左留白。
header / footer高度 0通过 height 和 render({ pageNumber, totalPages }) 定义页眉页脚。
contentFrame默认显示版心线颜色、粗细、线型；left / right 同时约束正文左右边界。
print.breakClasspage_print插入的分页元素类名；injectStyles 默认为开启。
maxPages300允许的最大页数。
assetTimeout3000 ms等待字体和图片就绪的时间上限。
